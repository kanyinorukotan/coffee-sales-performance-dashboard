# Coffee Sales Analysis in Excel

## Project Overview

This project analyzes coffee sales data from 2019 to 2022 using Microsoft Excel. I created an interactive dashboard to examine sales trends, product performance, customer behaviour, profitability, and performance across different countries.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- XLOOKUP
- Excel formulas
- Slicers
- Timeline filters
- Data cleaning
- Data visualization
